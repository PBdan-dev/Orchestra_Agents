# Changelog — agent-redaction

## 1.0.0 — 2026-11-01
- Première version : rédiger un document (compte rendu, rapport, note, lettre, article, publication) à partir de points ou de sources du projet, réécrire un texte, brouillon de mail (reprend agent-brouillons 1.0.3).
- Livrables en Markdown et, sur demande, en Word (.docx, bibliothèque standard).
- Contrôle par le code des nombres, jours, engagements et pièces jointes absents de la demande et des sources ; nombres disparus lors d'une réécriture.
- Mémoire propre : signature et ton préféré.
