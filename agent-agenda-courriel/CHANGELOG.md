# Changelog — agent-agenda-courriel

## 1.0.0 — 2026-11-01
- Première version, complément de Mail Adagio (pas de tri) : résumé des mails « Priority » et « To Do », mail ou réponse en brouillon Gmail avec envoi après validation, lecture de Google Agenda (iCal) avec créneaux libres, événement .ics et invitation après validation.
- Bibliothèque standard uniquement (imaplib, smtplib, email, iCalendar lu et écrit par le code, heure de Paris sans base de fuseaux).
- Identifiants dans le coffre-fort de Windows ; consignes cachées dans les mails retirées par le code avant le modèle.
